# مفتاح العام الجديد — نسخة الآيباد بدون مجلدات

هذه النسخة مخصصة للرفع السهل من الآيباد.

## كيف أرفعها؟
- فكّي الضغط.
- حددي جميع الملفات كلها دفعة واحدة.
- ارفعيها مباشرة إلى جذر المستودع في GitHub.
- يجب أن يكون `index.html` ظاهرًا مباشرة في الصفحة الرئيسية للمستودع.

## ملاحظة
لا توجد هنا أي مجلدات مثل assets أو screens أو icons.
كل شيء موجود في مستوى واحد لتسهيل الرفع.
