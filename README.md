# مفتاح العام الجديد — النسخة التفاعلية

هذه الحزمة جاهزة للرفع على GitHub Pages.

## المزايا
- الواجهة الرئيسية مطابقة بصريًا للتصميم المجسّم.
- خمس محطات تفاعلية: هدفي، سأتعلم، سأغيّر، سأترك أثرًا، رسالتي لنفسي.
- الكتابة والحفظ التلقائي على الجهاز.
- اسم الطالبة وشاشة ترحيب.
- إضاءة وصوت إنجاز خفيف.
- ملخص نهائي للرحلة.
- شهادة إنجاز بعد إكمال المحطات الخمس.
- PWA قابلة للتثبيت وتعمل دون اتصال بعد أول تحميل.

## الرفع على GitHub Pages
1. فك الضغط.
2. ارفعي محتويات مجلد The-Key-to-the-New-Year إلى جذر المستودع.
3. من Settings → Pages اختاري Deploy from a branch.
4. اختاري main / root ثم Save.
5. انتظري دقائق قليلة ثم افتحي رابط GitHub Pages.

مهم: ارفعي *محتويات* المجلد بحيث يكون index.html في جذر المستودع.
